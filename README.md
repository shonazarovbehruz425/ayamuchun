# EduBot

O'qituvchilar uchun yordamchi Telegram bot va Mini App.

## Xususiyatlar
- Fayllar ustida amallar (konvertatsiya)
- AI yordamchi (matnni xulosalash, tarjima qilish, dars rejasi tuzish)
- Avtomatik test yaratish (mavzu bo'yicha)
- Baholar jadvali bilan ishlash
- Telegram Mini App orqali boshqarish

## Talablar
- Python 3.12+
- Docker va Docker Compose

## O'rnatish

### Docker orqali
1. `.env` faylini sozlang
2. `docker-compose up -d --build`

### Oddiy o'rnatish
1. `pip install -r requirements.txt`
2. `python -m bot.main`

## Mini App sozlash
BotFather orqali webapp manzilini sozlang.
